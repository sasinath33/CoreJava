What is Java?

Java is a high-level, object-oriented programming language developed by Sun Microsystems in 1995.

Current owner:
Oracle Corporation.

Java follows the principle:

Write Once, Run Anywhere (WORA)

Meaning one Java program can run on Windows, Linux, and Mac without changing the code.

Interview Questions

Q1. Why Java is platform independent?

Answer:

Because Java code is converted into Bytecode which runs on JVM.

Q2. Difference between JDK and JRE?

JDK is used for development.

JRE is used for execution.

Q3. What is JVM?

Virtual machine that executes Java bytecode.

Q4. Explain WORA.

Write Once Run Anywhere.

Q5. Why Java is Secure?
