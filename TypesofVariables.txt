1. What is a Variable?

A variable is a named memory location used to store data. Its value can change during program execution.

Syntax:

dataType variableName = value;

Example:

int age = 25;

String name = "John";

double salary = 35000.50;

2. Why Do We Use Variables?

Variables help us:

Store data

Reuse values

Perform calculations

Improve code readability

Example Without Variable:

System.out.println(5000);

System.out.println(5000 + 1000);

Example With Variable:

int salary = 5000;

System.out.println(salary);

System.out.println(salary + 1000);

3. Rules for Naming Variables

✅ Valid:

studentName

age

salary123

_marks

$price

❌ Invalid:

123age

student-name

int

Rules:

Must start with a letter, _, or $.

Cannot start with a number.

Cannot use Java keywords.

Java is case-sensitive (age and Age are different).

10. Type Casting

Type casting means converting one data type into another.

There are two types:

Implicit (Widening)

Explicit (Narrowing)

Implicit Type Casting (Automatic)

Small data type → Large data type

byte → short → int → long → float → double

Example:

int number = 100;

double value = number;

 

System.out.println(value);

Output:

100.0

Explicit Type Casting (Manual)

Large data type → Small data type

double value = 99.99;

 

int number = (int) value;

 

System.out.println(number);

Output:

99

Note: Decimal part is removed.

13. Common Errors

1. Assigning Decimal to int

int number = 10.5;

❌ Error

Correct:

double number = 10.5;

2. Missing f for float

float price = 10.5;

❌ Error

Correct:

float price = 10.5f;

3. Missing L for large long values

long value = 8000000000;

❌ Error

Correct:

long value = 8000000000L;

4. Using Double Quotes for char

char grade = "A";

❌ Error

Correct:

char grade = 'A';

14. Interview Questions & Answers

1. What is a variable?

Answer: A variable is a named memory location used to store data that can change during program execution.

2. What are primitive data types?

Answer: Primitive data types are built-in data types used to store simple values such as int, char, boolean, and double.

3. Difference between float and double?

5. What is type casting?

Answer: Type casting is the process of converting one data type into another.

6. What is widening?

Answer: Automatic conversion from a smaller data type to a larger data type.

7. What is narrowing?

Answer: Manual conversion from a larger data type to a smaller data type using explicit casting.

8. What is the purpose of the final keyword?

Answer: It is used to declare constants whose values cannot be changed after initialization.
