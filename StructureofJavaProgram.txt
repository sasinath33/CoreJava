1. Structure of a Java Program

Every Java program follows a standard structure.

Basic Structure

// Package Declaration (Optional)

 

package com.demo;

 

// Import Statements (Optional)

 

import java.util.Scanner;

 

// Class Declaration

 

public class Hello {

 

    // Main Method

 

    public static void main(String[] args) {

 

        // Statements

 

        System.out.println("Welcome to Java");

 

    }

 

}

Structure Explanation

Part

Description

Package

Organizes classes into folders

Import

Imports predefined classes/packages

Class

Blueprint containing methods and variables

Main Method

Entry point of the program

Statements

Instructions executed by JVM

7. Java Naming Convention

Naming conventions improve readability and maintainability.

Class Name

Start with Capital Letter.

Use PascalCase.

Correct

Student

EmployeeDetails

BankAccount

Wrong

student

employee details

1Student

Variable Name

Start with lowercase.

Use camelCase.

Correct

studentName

employeeSalary

mobileNumber

Wrong

StudentName

student_name

1salary

Method Name

Always use camelCase.

Correct

display()

calculateTotal()

printMarks()

Package Name

Always lowercase.

Correct

com.company.project

student.management

Wrong

Student.Management

Constant Name

Use uppercase with underscores.

MAX_SIZE

PI_VALUE

DEFAULT_PORT
