Single Dimensional Array

Array in Java

1. Definition

• An array is a container object that stores a collection of data.

• It stores multiple values of the same datatype in a single variable.

• The index starts at 0.

Example:

int a = 90; // single variable

int b = 80; // single variable

// Instead, use an array:

int arr[] = {90, 80};

________________________________________

2. Syntax to Declare and Initialize Arrays

There are 3 common ways:

1. Declaration + Initialization together

datatype name[] = {elements};

Example:

int nums[] = {10, 20, 30};

2. Alternative declaration

datatype[] name = {elements};

Example:

String[] fruits = {"Apple", "Banana", "Mango"};

3. Using new keyword with size

datatype name[] = new datatype[length];

Example:

int marks[] = new int[5]; // size = 5

marks[0] = 90;

marks[1] = 80;

________________________________________

3. Accessing Elements

• Array elements are accessed using index.

• Index always starts at 0.

Example:

System.out.println(nums[0]); // prints 10

System.out.println(nums[2]); // prints 30

________________________________________

4. Printing Arrays

There are multiple ways:

(a) Using for loop

for(int i = 0; i < nums.length; i++) {

System.out.println(nums[i]);

}

(b) Using foreach loop -->Enhanced forloop

Syntax:

for(datatype variable : arrayName) {

// use variable

}

Example:

for(int n : nums) {

System.out.println(n);

}

Limitation: Foreach is unidirectional (can’t traverse backward).

(c) Using inbuilt method

import java.util.Arrays; // This line should be after package declaration and before class name..

System.out.println(Arrays.toString(nums));

________________________________________

5. Example with String Array

public class ArrayExample {

public static void main(String[] args) {

int age[] = {1,2,3,4,5};

// 1. Using for loop

for(int i=0; i<age.length; i++) {

System.out.println(age[i]);

}

// 2. Using foreach

for(int n : age) {

System.out.println(n);

}

// 3. Using Arrays.toString()

System.out.println(java.util.Arrays.toString(age));

}

}

________________________________________

Key Points

• Arrays store multiple values of the same type.

• Index starts from 0.

• Length of array = arrayName.length.

• Use loops or Arrays.toString() to print arrays.
