Syntax

}

8. Common Mistakes

Mistake 1: Using = Instead of ==

❌ Wrong

if (age = 18)

✅ Correct

if (age == 18)

Mistake 2: Missing Curly Braces

if (age >= 18)

    System.out.println("Eligible");

    System.out.println("Welcome");

Only the first statement belongs to the if.

Correct:

if (age >= 18) {

    System.out.println("Eligible");

    System.out.println("Welcome");

}

Mistake 3: Wrong Order in else-if

❌ Wrong

if (marks >= 35) {

    System.out.println("Pass");

} else if (marks >= 90) {

    System.out.println("Grade A");

}

The first condition (marks >= 35) will already match for marks of 90, so the second condition is never reached.

✅ Correct

if (marks >= 90) {

    System.out.println("Grade A");

} else if (marks >= 35) {

    System.out.println("Pass");

}

Always check the most specific/highest condition first.

9. Interview Questions & Answers

1. What is an if statement?

Answer: It executes a block of code only when the specified condition evaluates to true.

2. What is the difference between if and if-else?

If

if-else

Executes only when the condition is true

Executes one of two blocks depending on the condition

3. When should you use an else-if ladder?

Answer: When you need to test multiple conditions and execute the block for the first matching condition.

4. What is a nested if?

Answer: An if statement placed inside another if statement.

5. Can an if statement exist without an else?

Answer: Yes. The else block is optional.

6. Which block is executed in an else-if ladder?

Answer: Only the first condition that evaluates to true is executed. The remaining conditions are skipped.

13. Chapter Summary

Conditional statements control the program's decision-making.

Use if for a single condition.

Use if-else when there are two possible outcomes.

Use an else-if ladder when checking multiple conditions.

Use nested if when one condition depends on another.

Arrange conditions from the most specific to the least specific in an else-if ladder.

Always use == to compare primitive values and equals() to compare String values.

1. What is a Switch Statement?

A switch statement is used to select one block of code from multiple choices based on the value of an expression.

Instead of writing many if-else statements, you can use switch for cleaner and more readable code.

2. Syntax of Switch

switch(expression) {

 

    case value1:

        // Statements

        break;

 

    case value2:

        // Statements

        break;

 

    case value3:

        // Statements

        break;

 

    default:

        // Default statements

}

Flow Diagram

          Expression

               │

      ┌────────┼────────┐

      │        │        │

   case1    case2    case3

      │        │        │

      └────────┼────────┘

               │

           default

3. Example 1: Day of Week

public class SwitchDemo {

 

    public static void main(String[] args) {

 

        int day = 3;

 

        switch(day) {

 

            case 1:

                System.out.println("Monday");

                break;

 

            case 2:

                System.out.println("Tuesday");

                break;

 

            case 3:

                System.out.println("Wednesday");

                break;

 

            case 4:

                System.out.println("Thursday");

                break;

 

            default:

                System.out.println("Invalid Day");

 

        }

 

    }

 

}

Output

Wednesday

4. Example 2: Calculator

public class Calculator {

 

    public static void main(String[] args) {

 

        int a = 10;

        int b = 5;

        char operator = '+';

 

        switch(operator) {

 

            case '+':

                System.out.println(a + b);

                break;

 

            case '-':

                System.out.println(a - b);

                break;

 

            case '*':

                System.out.println(a * b);

                break;

 

            case '/':

                System.out.println(a / b);

                break;

 

            default:

                System.out.println("Invalid Operator");

 

        }

 

    }

 

}

Output

15

5. The break Statement

The break statement exits the switch after executing the matching case.

Without break, execution continues into the next case (fall-through).

Example (Without break)

int day = 1;

 

switch(day) {

 

    case 1:

        System.out.println("Monday");

 

    case 2:

        System.out.println("Tuesday");

 

    case 3:

        System.out.println("Wednesday");

 

}

Output

Monday

Tuesday

Wednesday

This is called fall-through.

6. The default Case

The default block runs when no case matches.

int number = 8;

 

switch(number) {

 

    case 1:

        System.out.println("One");

        break;

 

    default:

        System.out.println("Invalid Number");

 

}

Output

Invalid Number
