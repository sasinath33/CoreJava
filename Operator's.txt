1. What is an Operator?

An operator is a special symbol used to perform operations on variables and values.

Example:

int a = 10;

int b = 20;

int sum = a + b;

Here:

= → Assignment Operator

+ → Arithmetic Operator

Types of Operators in Java

Operators

│

├── Arithmetic Operators

├── Relational Operators

├── Logical Operators

├── Assignment Operators

├── Unary Operators

├── Increment/Decrement Operators

├── Ternary Operator

└── Bitwise Operators

Note: In this chapter, we will focus on the first four types.

1. String Concatenation

What is String Concatenation?

Concatenation means joining two or more strings using the + operator.

Syntax

String result = string1 + string2;

Example 1

public class ConcatenationDemo {

 

    public static void main(String[] args) {

 

        String firstName = "John";

        String lastName = "David";

 

        System.out.println(firstName + lastName);

 

    }

 

}

Output

JohnDavid

Example 2 (With Space)

String firstName = "John";

String lastName = "David";

 

System.out.println(firstName + " " + lastName);

Output

John David

Concatenating Variables

String name = "Alice";

int age = 22;

 

System.out.println("Name : " + name);

System.out.println("Age : " + age);

Output

Name : Alice

Age : 22

Concatenation with Numbers

System.out.println(10 + 20);

Output

30

But,

System.out.println("10" + "20");

Output

1020

Important Example

System.out.println("Sum = " + 10 + 20);

Output

Sum = 1020

Why?

"Sum = " + 10 → "Sum = 10"

"Sum = 10" + 20 → "Sum = 1020"

To get the correct sum:

System.out.println("Sum = " + (10 + 20));

Output

Sum = 30

9. Ternary Operator (? :)

The ternary operator is a shortcut for if-else when choosing between two values.

Syntax

condition ? valueIfTrue : valueIfFalse;

Example 1

int age = 20;

 

String result = (age >= 18) ? "Eligible" : "Not Eligible";

 

System.out.println(result);

Output

Eligible

Example 2

Find the larger number.

int a = 10;

int b = 20;

 

int max = (a > b) ? a : b;

 

System.out.println(max);

Output

20

Example 3

Check Even or Odd

int number = 12;

 

String result = (number % 2 == 0) ? "Even" : "Odd";

 

System.out.println(result);

Output

Even

10. Nested Ternary Operator

int a = 15;

int b = 20;

 

String result = (a > b) ? "A is Greater" : "B is Greater";

 

System.out.println(result);

Output

B is Greater

11. Common Mistakes

Mistake 1

System.out.println("Total = " + 10 + 20);

Output

Total = 1020

Correct

System.out.println("Total = " + (10 + 20));

Mistake 2

Confusing Prefix and Postfix

int a = 5;

 

System.out.println(a++);

Output

5

Many beginners expect 6, but the increment happens after the current value is used.

Mistake 3

Using the ternary operator for complex logic

condition ? statement1 : statement2;

Use the ternary operator only for simple decisions. For multiple conditions or complex blocks, prefer if-else.
