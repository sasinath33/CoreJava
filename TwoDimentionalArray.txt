TWO DIMENSIONAL ARRAY 

===============================

1. Definition:

-------------

Two-dimensional array is a collection of data elements arranged in rows and columns.

It is also called Matrix.

Syntax:

-------

datatype arrayName[][] = new datatype[row][col];

Example:

--------

int arr[][] = new int[3][3];

Initialization:

---------------

int arr[][] = {

{1, 2, 3},

{4, 5, 6},

{7, 8, 9}

};

Indexing starts from 0.

arr[0][0] = 1

arr[1][2] = 6

---------------------------

Input from User Example:

---------------------------

Scanner sc = new Scanner(System.in);

int row = sc.nextInt();

int col = sc.nextInt();

int arr[][] = new int[row][col];

for(int i = 0; i < row; i++){

for(int j = 0; j < col; j++){

arr[i][j] = sc.nextInt();

}

}

--------------------------------

Printing 2D Array (Nested Loop)

--------------------------------

for(int i = 0; i < arr.length; i++){

for(int j = 0; j < arr[i].length; j++){

System.out.print(arr[i][j] + " ");

}

System.out.println();

}

----------------------------------------

Printing using Arrays.deepToString()

----------------------------------------

System.out.println(Arrays.deepToString(arr));

----------------

Jagged Array

----------------

Rows with different number of columns.

int arr[][] = {

{1, 2, 3},

{4, 5},

{6, 7, 8, 9}

};

-----------------------

Useful Array Operations

-----------------------

1. Sum of all elements

-----------------------

int sum = 0;

for(int i=0;i<arr.length;i++){

for(int j=0;j<arr[i].length;j++){

sum += arr[i][j];

}

}

System.out.println("Sum = " + sum);

2. Find Maximum Element

-----------------------

int max = arr[0][0];

for(int i=0;i<arr.length;i++){

for(int j=0;j<arr[i].length;j++){

if(arr[i][j] > max){

max = arr[i][j];

}

}

}

System.out.println("Max = " + max);

3. Print Diagonal Elements

--------------------------

for(int i=0;i<arr.length;i++){

System.out.print(arr[i][i] + " ");

}

4. Print Row-wise

------------------

for(int i=0;i<arr.length;i++){

System.out.println(Arrays.toString(arr[i]));

}

------------------------------------

Types of Array in Java

------------------------------------

1. Single Dimensional Array → {1,2,3,4}

2. Two Dimensional Array → Matrix form

3. Jagged Array → Different size rows
